# POO en clase

Presentación interactiva y animada para enseñar Programación Orientada a Objetos (POO): clase y objeto, los cuatro pilares (abstracción, encapsulamiento, herencia y polimorfismo), objetos frente a arreglos y la actividad práctica «Del objeto al sistema».

**Ver la presentación:** https://billyprogramador.github.io/poo-en-clase/

## Cómo usarla

- Avanza con los botones de la barra inferior, las flechas del teclado o deslizando en el celular.
- El botón ☰ abre el índice para saltar a cualquier diapositiva.
- Cada diapositiva tiene algo para tocar: crear objetos, abstraer, probar el encapsulamiento, ver la herencia y escuchar el polimorfismo.

Es un único archivo `index.html` sin dependencias que instalar: también funciona abriéndolo directamente en el navegador.
